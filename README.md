# dunder-mifflin-infinity-analysis
Synthetic portfolio dataset inspired by *The Office*. Not official show/NBC data. All transaction values, costs, targets, and commission rates are invented for practice.

Analysis period: 2007-10-01 through 2008-05-15; project costs begin 2007-07-01.

Files:
- sales_orders.csv: Scranton conventional + genuine website orders
- dmi_website_ledger.csv: website-reported revenue, including records that may require reconciliation
- delivery_records.csv: warehouse fulfillment
- commission_ledger.csv: commission payments/holds
- sales_reps.csv: rep roster and commission rates
- customers.csv: customer master
- product_catalog.csv: price and unit-cost reference
- dmi_project_costs.csv: synthetic costs for ROI
- monthly_sales_targets.csv: optional performance context

The raw data intentionally contains duplicate records, inconsistent labels, missing matches, quantity discrepancies, cancellations/returns, and ambiguous attribution.
